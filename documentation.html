SAMAWA

Wedding Package Marketplace UI Template Documentation

Version 1.0.0

Project Overview

Samawa is a modern wedding package marketplace UI template focused on browsing packages by city, detailed vendor pages, and a smooth booking and checkout flow. This is a frontend-only template with no backend functionality.

🚀 HTML5 🎨 CSS3 🟨 JavaScript 🌬️ Tailwind CSS 🔤 Poppins Font 📱 Responsive Design 🖌️ UI Template Only

Key Features

🏙️ Browse by City

Discover packages by cities with curated listings and quick filters.

🎯 Package Details

Comprehensive package details with image gallery, pricing, and inclusions.

🛒 Seamless Checkout

Multi-step checkout with date selection, contact details, and confirmation.

📱 Responsive Design

Mobile-first layouts with consistent components and interactions.

Project Setup

Prerequisites

  • VS Code (Visual Studio Code)
  • Node.js (for installing dependencies with npm)
  • Live Server Extension for VS Code

Installation Steps

  1. Download ZIP file:

    Download the Samawa project ZIP file from the repository or available source.

  2. Extract ZIP file:

    Extract the downloaded ZIP file to your desired folder.

  3. Open extracted folder:

    Navigate to the extracted folder to view the project structure.

  4. Open project folder in VS Code:

    Open the folder in VS Code.

  5. Install dependencies:

    Run npm install (Tailwind CSS and Prettier will be installed).

  6. Start Tailwind CSS compiler:

    Run npm run dev to start the Tailwind CSS compiler in watch mode.

  7. Open pages with Live Server:

    Open any HTML file in src/pages/ with Live Server to preview.

Note: Live Server will auto-reload when you change HTML, CSS, or JavaScript files.
Tips: If Live Server has issues, restart VS Code or change the port.

How to Edit/Modify the Project

Making Changes to the Project

With Live Server running, you can start editing code. Setup and workflow are the same as the original instructions.

File Structure for Editing

  1. HTML Files:

    All HTML pages are in src/pages/.

    • src/pages/package-details.html - Package details page
    • src/pages/browse-by-city.html - Browse by city
    • src/pages/form-booking/checkout.html - Checkout
    • src/pages/form-booking/check-booking.html - Check booking
    • src/pages/form-booking/check-booking-result.html - Booking result
    • src/pages/form-booking/checkout-finished.html - Success page
  2. CSS Styling:

    Tailwind CSS v4 is used. Modify styles in two ways:

    • Tailwind classes: Add utilities directly in HTML
    • Custom CSS: Edit src/css/input.css
    • Compiled CSS: Output in src/css/output.css
    • Important: Run npm run dev to compile Tailwind changes
  3. JavaScript Functionality:

    JavaScript files are in src/scripts/:

    • navbar.js - Navigation functionality
    • accordion.js - Accordion interactions
    • datepicker.js - Date selection
    • modal.js - Modal open/close logic
    • swiper.js - Image carousel
    • tabs-checkout.js - Checkout tab handling
    • upload-input.js - Upload UI with preview
    • package-details-image-selection.js - Gallery selection
    • fix-a-href-path.js - Path utilities
  4. Images and Icons:

    Static assets are stored in the public/ directory:

    • public/icons/ - SVG icons
    • public/images/ - PNG images and graphics

Development Workflow

  1. Start Tailwind CSS Compiler: Run npm run dev.
  2. Start Live Server: Preview pages live.
  3. Edit Files: Modify HTML/CSS/JS.
  4. Save Changes: Compiler and Live Server will reload.
  5. Test Changes: Verify in the browser.
Critical: Run npm run dev so Tailwind changes are compiled.

Common Modifications

🎨 Change Colors and Styling

Update color scheme via src/css/input.css or Tailwind classes in HTML.

📝 Update Text Content

Edit text directly in HTML files.

🖼️ Replace Images and Icons

Replace assets in public/images/ and public/icons/.

⚙️ Modify Functionality

Edit JS in src/scripts/ to customize interactions.

📱 Adjust Layout

Modify HTML structure and Tailwind classes to change layouts.

🔧 Add New Pages

Create new HTML files following the existing structure.

Pro Tip: Backup the project before large changes.
Important: Ensure custom CSS does not conflict with Tailwind utilities.
UI Template Only: Forms do not submit and data does not persist without a backend.
